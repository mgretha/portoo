Noorshaf.id adalah toko online abaya modest yang mendukung produk Ready Stock dan Pre-Order, pembayaran Duitku, serta pengiriman Biteship. Sebagai Frontend Developer Intern di Ashira Group, saya mengerjakan Admin Dashboard-nya untuk mendukung operasional toko, mulai dari pengelolaan produk dan pesanan hingga pengiriman, pelanggan, laporan, dan manajemen staf.

✦ Key Impact

  • Shipped admin modules to production that run the store's daily operations — products, orders, shipping, pre-orders, customers, and staff.
  • Turned production recaps into a one-click Excel export grouped by color and size.
  • Prevented duplicate shipments and kept cost prices hidden from staff through role-based access.

Eksplorasi Kontribusi Kunci (Klik Tab):

A Admin Dashboard Foundation

  • Developed responsive admin layouts, sidebar navigation, header, and login page.
  • Built a product listing page with search, filters, and responsive desktop and mobile layouts.
  • Developed product creation and editing forms covering product information, sizes, colors, image uploads, stock, SKU, and Pre-Order configuration.
  • Implemented basic store settings.

B Order Management

  • Built order listing and detail pages with status-based navigation.
  • Displayed payment information and payment attempt history.
  • Implemented order cancellation with reasons, admin notes, and WhatsApp customer communication.
  • Developed payment reminder functionality.

C Shipping Integration

  • Implemented shipping workflows integrated with the Biteship API.
  • Added shipment information, tracking, shipping label printing, and WhatsApp tracking notifications.
  • Implemented safeguards against duplicate shipment creation caused by repeated actions.

D Pre-Order & Customer Management

  • Developed Pre-Order listing and detail pages.
  • Displayed color-based quotas, daily order charts, production recaps by color and size, and customer order lists.
  • Built customer search, detail views, and WhatsApp follow-up functionality.

E Reporting, Dashboard, and Access Control

  • Implemented Excel export for production recaps.
  • Developed staff management with role-based permissions.
  • Built a responsive dashboard for daily tasks.
  • Helped protect sensitive business information through access restrictions, including restrictions on staff access to cost prices.

✦ Technical Highlights

  • API integration using Zod-based contracts and validation.
  • Mobile-first responsive admin interface with loading, error, and retry handling.
